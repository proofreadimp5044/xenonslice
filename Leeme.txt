XenonSlice — Zonas de CPU para AMD 8c/16t
==========================================

Reparte el sistema, el audio y las apps entre los núcleos en CPUs AMD de
8 núcleos / 16 hilos de un solo chip (Ryzen Z1 Extreme y similares).

- app.slice       → hilos 0-11 (6 núcleos para juegos y apps)
- background.slice → hilos 12-15 (2 núcleos para el sistema)
- system.slice / init.scope → hilos 12-15
- session.slice / user.slice → hilos 0-15

REQUISITOS
----------
- CPU AMD con exactamente 16 hilos (8 núcleos con SMT), un solo dominio L3.
  Probado en Ryzen Z1 Extreme. El instalador comprueba la topología y
  cancela si no es compatible.
- Linux con systemd.
- Plasma (probado en CachyOS). Para la interfaz: PyQt6 o PySide6.
- El usuario debe poder usar sudo.

INSTALACIÓN
-----------
IMPORTANTE: descomprime esta carpeta en tu carpeta personal.
Debe quedar exactamente en:   ~/xenonslice

1. Abre una terminal y ejecuta UNA vez:

       cd ~/xenonslice
       chmod +x preparar.sh
       ./preparar.sh

   (o doble clic en «Preparar permisos.desktop»)

2. Doble clic en «Instalar XenonSlice.desktop».
   Se abrirá una terminal, te pedirá la contraseña y dejará todo listo.

3. Abre «XenonSlice» desde el menú de aplicaciones.
   Verás una terminal detrás de la interfaz: es normal, la terminal
   permite ver errores si algo falla. Al cerrar la app, se cierra sola.

USO
---
  xenonslice            abre la interfaz
  xenonslice aplicar    aplica la configuración (pide contraseña)
  xenonslice estado     comprueba qué está configurado
  xenonslice revertir   vuelve a 0-15
  xenonslice topologia  verifica que el equipo es compatible

Tras aplicar o revertir, cierra sesión (o reinicia) para que systemd
aplique los cpusets a system.slice e init.scope. El audio se puede
reiniciar al momento con «reiniciar audio» en la GUI o
`xenonslice aplicar --reiniciar-audio`.

DESINSTALAR
-----------
Doble clic en «Desinstalar XenonSlice.desktop» o ejecuta:

       cd ~/xenonslice
       ./desinstalar-todo.sh

Revuelve la configuración (todo vuelve a 0-15) y quita la app.

SI ALGO FALLA
-------------
- Instalación:    /tmp/xenonslice-instalar.log
- Desinstalación: /tmp/xenonslice-desinstalar.log
- App desde menú: la terminal muestra el error (no se cierra si falla)
